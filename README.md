## 🚀 Featured Projects

### [StockBridge](https://github.com/semaakyavuz/StockBridge) — Inventory Management API ([Live Demo](https://stockbridge-enb4.onrender.com))
ASP.NET Core 8 backend with OAuth 2.0 (PKCE) login, JWT-based roles, background sync jobs, and AI-assisted stock insights (Groq / LLaMA 3.1). Tested with xUnit, checked with SonarCloud, deployed with Docker.

### [Document-Intelligence-Agent](https://github.com/semaakyavuz/Document-Intelligence-Agent) — Multi-Agent Invoice Audit System ([Live Demo](https://document-intelligence-agent-rx07.onrender.com))
Four AI agents (LangGraph) read an invoice image, find the rules that apply (RAG with ChromaDB), check the invoice, and write an audit report with a 0-100 risk score. Tested on 502 real invoices with 95.9% accuracy, 346 automated tests, deployed with Docker.

### [IT-Ticket-Triage-Agent](https://github.com/semaakyavuz/IT-Ticket-Triage-Agent) — AI Support Agent
A Python agent that reads IT support tickets, decides their category and priority, finds similar past tickets (RAG), and suggests a resolution. Built with LangGraph, FastAPI, and a vector database; includes a dashboard and a full test suite.

### [anon-paper-system](https://github.com/semaakyavuz/anon-paper-system) — Academic Paper Anonymization Platform
A FastAPI + React platform that removes author-identifying details from academic papers before peer review, with role-based access and an audit trail.

### [RecipeAPI](https://github.com/semaakyavuz/RecipeAPI)
A second ASP.NET Core API built to practice the same testing and CI/CD setup (xUnit, GitHub Actions) on a new domain.
